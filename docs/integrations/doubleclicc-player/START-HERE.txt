The wrapper automatically selects a portrait composition below 768px of
container width. It loops silently, hides the default playback controls, and
provides its own pause/play button. Visitors who prefer reduced motion see a
static branded fallback. The real CTA remains available throughout playback.

The CTA is intentionally unconfigured: pass diagnosticHref for a link or
onDiagnostic for a form-opening callback. A callback takes priority if both
are provided. No CTA appears if neither is provided.
